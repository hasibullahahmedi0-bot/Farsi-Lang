# 📚 آموزش ابتدایی زبان فارسی

## خوش آمدید! 👋

این آموزش شما را با مبانی زبان برنامه‌نویسی **فارسی** آشنا می‌کند.

---

## 1️⃣ شروع سریع

### نوشتن "سلام جهان"

```farsi
نوشتن("سلام جهان!")
```

ذخیره کنید با نام `hello.fr` و اجرا کنید:
```bash
farsi hello.fr
```

---

## 2️⃣ متغیرها

```farsi
// متغیر رشته‌ای
نام = "علی"

// متغیر عددی
سن = 25

// متغیر منطقی
فعال = درست

// نمایش متغیرها
نوشتن(نام)
نوشتن(سن)
نوشتن(فعال)
```

---

## 3️⃣ عملیات ریاضی

```farsi
الف = 10
ب = 5

// جمع
جمع = الف + ب
نوشتن(جمع)  // 15

// تفریق
تفریق = الف - ب
نوشتن(تفریق)  // 5

// ضرب
ضرب = الف * ب
نوشتن(ضرب)  // 50

// تقسیم
تقسیم = الف / ب
نوشتن(تقسیم)  // 2

// توان
توان = الف ** 2
نوشتن(توان)  // 100
```

---

## 4️⃣ شرط‌ها (If/Else)

```farsi
سن = 20

اگر (سن >= 18) {
    نوشتن("شما بزرگسال هستید")
} وگرنه {
    نوشتن("شما نابالغ هستید")
}
```

---

## 5️⃣ حلقه‌ها

### حلقه For
```farsi
برای (شمارنده = 1; شمارنده <= 5; شمارنده = شمارنده + 1) {
    نوشتن(شمارنده)
}
// نتیجه: 1 2 3 4 5
```

### حلقه While
```farsi
شمار = 1
تا‌زمانی_که (شمار <= 5) {
    نوشتن(شمار)
    شمار = شمار + 1
}
// نتیجه: 1 2 3 4 5
```

---

## 6️⃣ توابع

```farsi
// تعریف تابع
تابع جمع(الف، ب) {
    برگردان الف + ب
}

// استفاده از تابع
نتیجه = جمع(3, 7)
نوشتن(نتیجه)  // 10
```

---

## 7️⃣ لیست‌ها (آرایه‌ها)

```farsi
// ایجاد لیست
اعداد = [1, 2, 3, 4, 5]

// دسترسی به عنصر
نوشتن(اعداد[0])  // 1

// طول لیست
نوشتن(اعداد.طول())  // 5
```

## 8️⃣ مقایسه‌ها

```farsi
الف = 10
ب = 5

برابر = (الف == ب)       // false
نابرابر = (الف != ب)     // true
کمتر = (الف < ب)         // false
بیشتر = (الف > ب)        // true
کمتر_یا_برابر = (الف <= ب)  // false
بیشتر_یا_برابر = (الف >= ب) // true
```

---

## 9️⃣ منطق بولی

```farsi
درست = درست
غلط = غلط

نتیجه1 = درست و درست   // درست
نتیجه2 = درست یا غلط   // درست
نتیجه3 = نه درست       // غلط
```

## 🔟 مثال کامل: جدول ضرب

```farsi
برای (ردیف = 1; ردیف <= 3; ردیف = ردیف + 1) {
    برای (ستون = 1; ستون <= 3; ستون = ستون + 1) {
        حاصل = ردیف * ستون
        نوشتن(حاصل)
    }
}
```

---

## 📝 نکات مهم

1. **کامنت**: استفاده از `//` برای نوشتن توضیح
2. **نقطه و ویرگول**: در انتهای دستورات اختیاری است
3. **بلوک کد**: از `{` و `}` برای گروه‌بندی استفاده کنید
4. **تورفتگی**: کد خود را تورفته بنویسید

## 🎯 تمرین‌ها

### تمرین 1: فاکتوریل
یک تابع برای محاسبه فاکتوریل بنویسید:

```farsi
تابع فاکتوریل(ن) {
    اگر (ن <= 1) {
        برگردان 1
    }
    برگردان ن * فاکتوریل(ن - 1)
}

نوشتن(فاکتوریل(5))  // 120
```

### تمرین 2: جستجوی در لیست
یک تابع برای جستجوی عنصر در لیست بنویسید:

```farsi
اعداد = [10, 20, 30, 40, 50]

برای (شمارنده = 0; شمارنده < 5; شمارنده = شمارنده + 1) {
    اگر (اعداد[شمارنده] == 30) {
        نوشتن("پیدا شد!")
    }
}
```
